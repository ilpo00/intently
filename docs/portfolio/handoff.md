# Portfolio handoff — Intently ↔ portfolio site

The interface between this repository and Ilmari's portfolio-site project,
which is built in a separate repository and a separate working session.

**Rule:** each side writes only in its own repo. Artifacts cross by path or URL;
the portfolio side copies what it needs. This file is owned by the Intently
side and is the single place to check what is ready.

_Last updated: 2026-09-30._
